# 4.3 Eksekusi Transaksi Dummy sebagai Beban Sistem

Dokumen ini berfungsi sebagai panduan teknis implementasi transaksi dummy pada web prototype
untuk memberikan beban sistem yang terkontrol pada jaringan Hyperledger Fabric.

## Tujuan Teknis
- Menghasilkan transaksi tulis (write transaction) yang seragam
- Memastikan setiap transaksi memicu proses ordering + consensus + commit
- Menjadikan konsensus (Raft / SmartBFT) sebagai bottleneck utama yang diuji

## Spesifikasi Transaksi Dummy
Transaksi dummy HARUS memenuhi spesifikasi berikut:

- Jenis: Write transaction
- Ukuran payload: relatif konstan
- Tidak ada dependency antar transaksi
- Tidak ada branching logic

  "txId": "TX-000001",
  "createdAt": "ISO-8601",
