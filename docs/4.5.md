# 4.5 Pengelompokan Data Kinerja Sistem

Dokumen ini mengatur bagaimana data hasil eksekusi dikonversi
menjadi parameter kinerja yang siap dianalisis.

## Tujuan Teknis
- Menghasilkan metrik performa konsisten
- Memastikan data Raft dan SmartBFT comparable

## Instruksi Coding

### 1. Struktur Data Hasil Uji
Gunakan struktur data standar berikut:

```json
{
  "consensus": "raft",
  "txTotal": 500,
  "txSuccess": 500,
  "durationSec": 25
}
