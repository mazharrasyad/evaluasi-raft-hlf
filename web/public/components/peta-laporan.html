Peta Laporan Wilayah

Grafik batang hierarkis ini menampilkan rekapitulasi laporan berdasarkan data simulasi yang tersimpan di session browser. Klik setiap batang wilayah untuk menelusuri rincian hingga tingkat kelurahan.

Belum ada data simulasi yang dapat ditampilkan. Buat data simulasi terlebih dahulu untuk melihat persebaran laporan per wilayah.

Dataset wilayah diambil dari repositori wilayah-indonesia dan dipadankan dengan catatan simulasi. Data tidak disimpan permanen dan akan hilang ketika sesi browser berakhir.
