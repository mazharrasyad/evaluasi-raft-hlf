Daftar Rute Server

Ringkasan endpoint yang tersedia pada konfigurasi Express di app.js.

GET /

Menayangkan halaman dashboard utama.

GET *

Fallback untuk seluruh jalur lain yang turut mengirimkan halaman dashboard.

Static /

Melayani aset statis dari direktori public.

Static /wilayah-indonesia

Dataset wilayah tersedia sebagai aset statis di direktori wilayah-indonesia.

GET /api/check-network

Menjalankan pemeriksaan kesehatan jaringan dan mengembalikan ringkasan status dalam format JSON.
