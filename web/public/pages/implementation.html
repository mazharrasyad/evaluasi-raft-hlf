Chapter 4.2

Blockchain Testing Environment Implementation

Preparing the Hyperledger Fabric blockchain network ready for testing, with two separate consensus configurations: Network A (RAFT) and Network B (SmartBFT).

Key Principle: Both environments are created with equivalent specifications to ensure fair comparison. Any performance differences in later stages can be attributed directly to the consensus mechanism characteristics, not environmental factors.

Consensus Configuration Comparison

The key configuration difference between RAFT and SmartBFT lies in the orderer configuration:

RAFT Configuration (configtx.yaml)
Orderer:
  OrdererType: etcdraft
  EtcdRaft:
    Consenters:
      - Host: orderer.example.com
        Port: 7050
      - Host: orderer2.example.com
      - Host: orderer3.example.com
SmartBFT Configuration (configtx.yaml)
Orderer:
  OrdererType: BFT
  SmartBFT:
    Consenters:
      - Host: orderer.example.com
