Pembuatan Network Blockchain

Menjelaskan proses menyalakan jaringan Raft dan SmartBFT di VPS hingga status network siap untuk menerima transaksi.

Langkah Utama

  1. 1. Jalankan script deployment jaringan Raft.
  2. 2. Jalankan script deployment jaringan SmartBFT.
  3. 3. Verifikasi container orderer dan peer aktif.
  4. 4. Simpan log status network up.

Artefak Visual

Sertakan screenshot status container, output perintah start, dan diagram ringkas topologi jaringan.

Placeholder Perintah

./network.sh up -o raft
./network.sh up -o smartbft
