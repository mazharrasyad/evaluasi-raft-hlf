Sub Bab 4.4.2

Perancangan Data Simulasi

Menentukan format payload dummy dan parameter transaksi yang akan dikirim ke jaringan untuk tiap skenario beban.

Format Payload

{
  "id": "<tx-id>",
  "timestamp": "<timestamp>",
  "payload": "<dummy-data>",
  "kategori": "{BEBAN_TRANSAKSI}"
}

Parameter Input

  • Jumlah transaksi: {JUMLAH_TRANSAKSI_RENDAH}/{JUMLAH_TRANSAKSI_SEDANG}/{JUMLAH_TRANSAKSI_TINGGI}
  • Concurrency: {CONCURRENCY_LEVEL}
  • Jumlah percobaan: {JUMLAH_PERCOBAAN}

Artefak Pendukung

Screenshot form input pada web prototype dan tabel parameter yang digunakan.
