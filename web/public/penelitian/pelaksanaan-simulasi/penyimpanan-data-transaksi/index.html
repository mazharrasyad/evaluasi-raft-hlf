Sub Bab 4.4.4

Penyimpanan Data Transaksi

Menjamin semua data transaksi, log, dan hasil monitoring tersimpan rapi untuk proses analisis berikutnya.

Jenis Data yang Disimpan

  • Log transaksi (JSON/CSV).
  • Snapshot resource usage per interval.
  • Log error atau transaksi gagal.

Struktur Penyimpanan

/data/hasil-simulasi/
├── raft/
│   ├── log-transaksi.jsonl
│   └── resource-usage.csv
└── smartbft/
    ├── log-transaksi.jsonl
    └── resource-usage.csv
