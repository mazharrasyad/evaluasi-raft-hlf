Detail Jaringan Hyperledger Fabric

Ringkasan konfigurasi jaringan Fabric yang digunakan untuk evaluasi konsensus RAFT, mencakup versi komponen, struktur organisasi, dan topologi peer yang aktif.

Versi Hyperledger Fabric

Fabric runtime 2.5.13 dengan Fabric CA 1.5.15 sebagai standar ketika jaringan dihidupkan melalui network.sh.

Konsensus Orderer

Orderer menggunakan mode etcdraft dengan node konsenter yang tersertifikasi TLS untuk memastikan pemilihan leader deterministik.

Channel & Database

Channel default channel-standard menggunakan penyimpanan state LevelDB dan dapat disiapkan otomatis melalui createChannel.

Baseline Chaincode

Chaincode pelaporan berbahasa JavaScript menjadi contoh awal sebelum data produksi diunggah melalui antarmuka simulasi.

Layanan Orderer RAFT

Jaringan memiliki satu node orderer orderer.example.com (port 7050) yang menjalankan TLS penuh serta endpoint operasional pada port 9443 untuk metrik Prometheus.

  • Koneksi client & server TLS menggunakan sertifikat dari MSP OrdererMSP.
  • Cluster RAFT mengikuti konfigurasi konsenter tunggal sehingga setiap transaksi membutuhkan leader tunggal yang stabil.

Keanggotaan & MSP

Topologi identitas mencakup OrdererOrg serta dua organisasi aplikasi dengan hak baca/tulis dan endorsement tersendiri.

  • OrdererOrg / OrdererMSP – endpoint orderer dan admin orderer.
  • Org1MSP – memiliki hak endorsement dan akses klien untuk Org1.
  • Org2MSP – struktur kebijakan identik untuk Org2.

Topologi Peer

Setiap organisasi mengoperasikan satu peer utama dengan TLS, endpoint gRPC, dan port observasi.

peer0.org1.example.com
gRPC 7051 • Chaincode 7052 • Metrics 9444 • MSP Org1MSP
peer0.org2.example.com
gRPC 9051 • Chaincode 9052 • Metrics 9445 • MSP Org2MSP

Kemampuan Tambahan

Skrip otomatis memungkinkan penyediaan jaringan standar maupun variasi BFT melalui flag -bft, sekaligus mendukung mode Chaincode-as-a-Service untuk proses deploy yang terkontrol.
