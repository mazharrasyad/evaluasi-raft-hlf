Bab 4.5.3

Resource Usage

Resource usage merupakan metrik yang memantau penggunaan sumber daya komputasi selama simulasi berjalan, mencakup CPU (Central Processing Unit), memori (RAM), dan I/O (Input/Output) disk. Pemantauan resource usage penting untuk memahami efisiensi sistem dan kebutuhan infrastruktur yang diperlukan untuk menjalankan jaringan blockchain dengan performa optimal.

Data resource usage dikumpulkan secara periodik selama simulasi berjalan, dengan interval pengambilan setiap 5 detik. Monitoring dilakukan pada semua node dalam jaringan, termasuk orderer nodes dan peer nodes, untuk memberikan gambaran komprehensif tentang distribusi beban kerja dan utilisasi resource pada setiap komponen sistem.

Komponen yang Dimonitor

O Orderer Nodes

Node yang bertanggung jawab untuk ordering transaksi dan konsensus RAFT. Biasanya 3-5 node untuk fault tolerance.

P Peer Nodes

Node yang menyimpan ledger dan menjalankan chaincode. Melakukan endorsement dan commit transaksi.

Faktor-faktor yang Mempengaruhi Resource Usage

1 Transaction Volume

Jumlah transaksi per detik mempengaruhi beban CPU dan I/O secara langsung.

2 Payload Size

Ukuran data transaksi mempengaruhi penggunaan memory dan bandwidth.

3 Block Size

Konfigurasi block size mempengaruhi pola I/O dan memory usage.

4 State Database

Ukuran world state dan index mempengaruhi query performance.

5 Chaincode Complexity

Kompleksitas smart contract mempengaruhi CPU saat eksekusi.

6 Network Topology

Jumlah node dan konfigurasi endorsement policy.

Catatan Penting

  • 1. Monitoring dilakukan menggunakan Docker stats API dengan interval pengambilan setiap 5 detik.
  • 2. Peak usage penting untuk capacity planning - pastikan sistem memiliki headroom yang cukup.
