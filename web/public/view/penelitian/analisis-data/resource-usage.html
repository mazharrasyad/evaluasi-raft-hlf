Bab 4.5.3

Resource Usage

Resource usage merupakan metrik yang memantau penggunaan sumber daya komputasi selama simulasi berjalan, mencakup CPU (Central Processing Unit), memori (RAM), dan I/O (Input/Output) disk. Pemantauan resource usage penting untuk memahami efisiensi sistem dan kebutuhan infrastruktur yang diperlukan untuk menjalankan jaringan blockchain dengan performa optimal.

Data resource usage dikumpulkan secara periodik selama simulasi berjalan, dengan interval pengambilan setiap 5 detik. Monitoring dilakukan pada semua node dalam jaringan, termasuk orderer nodes dan peer nodes, untuk memberikan gambaran komprehensif tentang distribusi beban kerja dan utilisasi resource pada setiap komponen sistem.
