Bab 4.6.2

Ringkasan Hasil

Sub bab 4.6.2 merangkum hasil evaluasi performa berdasarkan empat parameter utama analisis data: Throughput (kemampuan memproses transaksi per detik), Latency (waktu respons), Resource Usage (penggunaan CPU dan memori), serta Fault Tolerance (ketahanan terhadap kegagalan node). Ringkasan ini mencakup empat konfigurasi jaringan (Fabric 2 dan 3 dengan RAFT standar maupun varian), termasuk opsi SmartBFT pada Fabric v3 varian, sehingga memudahkan perbandingan lintas skenario.

Fokus Ringkasan 4.6.2

Panduan membaca bagian ringkasan hasil

Statistik Keseluruhan

Menyajikan jumlah transaksi, success rate, throughput rata-rata, dan latency rata-rata sebagai gambaran umum performa.

Perbandingan Antar Network

Membandingkan empat konfigurasi jaringan untuk mengidentifikasi keunggulan performa pada skenario beban transaksi.

Analisis Parameter

Menjelaskan hasil per parameter (throughput, latency, resource usage, fault tolerance) sehingga mudah dikaitkan dengan tujuan penelitian.

Interpretasi Hasil

Menyediakan narasi singkat untuk menafsirkan perbedaan antar konfigurasi berdasarkan data simulasi yang dimuat.
