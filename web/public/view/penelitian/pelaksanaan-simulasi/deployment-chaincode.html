Bab 4.4.2

Deployment Chaincode

Pada tahap ini, dilakukan pembuatan channel untuk setiap jaringan Hyperledger Fabric yang akan digunakan dalam evaluasi performa konsensus RAFT. Berikut adalah perintah untuk membuat channel pada masing-masing konfigurasi jaringan.

Fabric 2

Raft Standard

Perintah Pembuatan Channel:

cd fabric-2/raft-standard/network && ./network.sh createChannel -c fabric2-channel-standard
Fabric 2

Raft Variant

Perintah Pembuatan Channel:

cd fabric-2/raft-variant/network && ./network.sh createChannel -c fabric2-channel-variant
Fabric 3

Raft Standard

Perintah Pembuatan Channel:

cd fabric-3/raft-standard/network && ./network.sh createChannel -c fabric3-channel-standard
Fabric 3

Raft Variant

Perintah Pembuatan Channel:

cd fabric-3/raft-variant/network && ./network.sh createChannel -c fabric3-channel-variant
