Input Data Simulasi

Halaman ini memungkinkan Anda untuk memasukkan data simulasi laporan maladministrasi ke dalam masing-masing blok fabric network. Data yang diinput akan dikirim ke network yang Anda pilih untuk kemudian dianalisa perbedaan performa antar network.

Pilih Target Network

Pilih satu atau lebih network blockchain yang akan menerima data simulasi. Anda dapat memilih untuk mengirim data ke semua network sekaligus untuk membandingkan performa.
