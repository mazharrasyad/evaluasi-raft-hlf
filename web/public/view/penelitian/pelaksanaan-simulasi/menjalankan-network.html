Pembuatan Network Blockchain

Pembuatan network blockchain merupakan tahap penting dalam membangun jaringan Hyperledger Fabric. Tahap ini meliputi pembuatan channel dan menyalakan jaringan untuk memastikan komunikasi privat antara subset organisasi dalam jaringan. Gunakan dashboard berikut untuk menyalakan, mematikan, dan memeriksa status jaringan Fabric 2 dan Fabric 3.

Fabric 2 Networks

Jalankan pemeriksaan npm run check-network secara langsung dari dashboard untuk memastikan setiap jaringan RAFT siap digunakan.

Pemeriksaan akan menghubungi peer peer0.org1.fabric2.standard.com dan menjalankan transaksi GetAllCatatan untuk memastikan chaincode merespons.

Pastikan jaringan Hyperledger Fabric telah dijalankan sebelum memulai pemeriksaan.
