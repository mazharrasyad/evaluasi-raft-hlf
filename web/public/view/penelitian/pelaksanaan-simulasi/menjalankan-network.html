Pembuatan Network Blockchain

Pembuatan network blockchain merupakan tahap penting dalam membangun jaringan Hyperledger Fabric. Tahap ini meliputi pembuatan channel dan menyalakan jaringan untuk memastikan komunikasi privat antara subset organisasi dalam jaringan. Gunakan dashboard berikut untuk menyalakan, mematikan, dan memeriksa status jaringan Fabric 2 dan Fabric 3.

Network Management

Kelola semua jaringan RAFT (Fabric 2 dan Fabric 3) dari satu dashboard terpadu.

Gunakan tombol di bawah untuk menjalankan, menghentikan, atau memeriksa status semua jaringan blockchain.

Pastikan Docker dan semua dependensi telah terinstal sebelum menjalankan network.
