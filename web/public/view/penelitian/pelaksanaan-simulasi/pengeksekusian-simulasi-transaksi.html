Pengeksekusian Simulasi Transaksi

Pengeksekusian simulasi transaksi merupakan tahap dimana data simulasi yang telah dirancang akan dijalankan ke dalam jaringan blockchain untuk menguji performa sistem. Data simulasi akan dikirimkan ke semua network (Fabric 2 RAFT Standard, Fabric 2 RAFT Variant, Fabric 3 RAFT Standard, dan Fabric 3 RAFT Variant) dengan berbagai kategori beban untuk mengukur throughput, latency, dan resource usage.
