Pengeksekusian Simulasi Transaksi

Pengeksekusian simulasi transaksi merupakan tahap dimana data simulasi yang telah dirancang akan dijalankan ke dalam jaringan blockchain untuk menguji performa sistem. Anda dapat memilih network mana saja yang akan menerima data simulasi (Fabric 2 RAFT Standard, Fabric 2 RAFT Variant, Fabric 3 RAFT Standard, dan/atau Fabric 3 RAFT Variant) dengan berbagai kategori beban untuk mengukur throughput, latency, dan resource usage.

Simulasi Fault Tolerance

Testing

Generate data simulasi dengan skenario kegagalan untuk mengukur fault tolerance sistem pada berbagai tingkat beban.

Apa itu Fault Tolerance Testing?

Pengujian fault tolerance mengukur kemampuan sistem blockchain untuk tetap beroperasi meskipun terjadi kegagalan pada beberapa komponen. Data simulasi ini mencakup skenario seperti: node failure, network partition, timeout, invalid transaction, dan consensus failure.

Pilih Kategori Beban untuk Fault Tolerance

Skenario Kegagalan

Pilih jenis kegagalan yang akan disimulasikan untuk mengukur fault tolerance.

Jumlah Transaksi Gagal

Range yang direkomendasikan untuk Beban Ringan: 50-100 transaksi gagal (Failure Rate: 5-10%)

Preview Data Fault Tolerance

Metrik yang Diukur

Recovery Time

Waktu yang dibutuhkan sistem untuk pulih dari kegagalan.

Success Rate Under Failure

Persentase transaksi yang berhasil saat terjadi kegagalan.

Latency Impact

Peningkatan latency saat terjadi kegagalan dibanding normal.

Error Distribution

Distribusi jenis error yang terjadi pada sistem.

Cascade Failure Rate

Tingkat kegagalan beruntun yang terjadi.

RAFT Leader Election

Waktu pemilihan leader baru saat leader gagal.
