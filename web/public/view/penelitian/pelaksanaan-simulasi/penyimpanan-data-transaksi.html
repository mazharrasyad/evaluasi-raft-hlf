Penyimpanan Data Transaksi

Halaman ini menampilkan data transaksi yang tersimpan pada semua network blockchain dalam satu tabel gabungan. Data diambil dari state database setiap network menggunakan API GET pelaporan. Anda dapat melihat semua record yang telah disubmit ke network Fabric 2 RAFT Standard, Fabric 2 RAFT Variant, Fabric 3 RAFT Standard, dan Fabric 3 RAFT Variant, lengkap dengan informasi network dan kategori beban. Tampilan dibatasi 4 rows per halaman untuk perbandingan yang lebih fokus.
