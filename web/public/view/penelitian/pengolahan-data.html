Bab 4.5

Pengolahan Data

Pengolahan data merupakan tahap analisis terhadap hasil simulasi transaksi yang telah dilaksanakan pada berbagai jaringan blockchain HLF. Pada tahap ini, data yang telah dikumpulkan dari empat varian jaringan (Fabric 2 RAFT Standard, Fabric 2 RAFT Variant, Fabric 3 RAFT Standard, dan Fabric 3 RAFT Variant) akan dianalisis untuk mengidentifikasi pola kinerja, mengukur metrik-metrik penting, dan membandingkan performa antar varian.

Proses pengolahan data meliputi dua tahapan utama. Pertama, dilakukan pengumpulan dan validasi log dari setiap network untuk memastikan integritas dan kelengkapan data yang diperoleh. Kedua, dilakukan pengolahan statistik berupa perhitungan nilai rata-rata dari berbagai metrik kinerja serta visualisasi data dalam bentuk grafik perbandingan. Analisis komprehensif ini akan memberikan gambaran jelas mengenai karakteristik dan efisiensi masing-masing varian algoritma konsensus RAFT dalam konteks blockchain Hyperledger Fabric.

Bab 4.5.1

Pengumpulan dan Validasi Log

Pengumpulan log transaksi dari API masing-masing network dan validasi data untuk memastikan kelengkapan dan konsistensi data simulasi yang diperoleh dari keempat varian jaringan blockchain.

Bab 4.5.2

Pengolahan Nilai Rata-Rata dan Grafik

Analisis statistik data simulasi dengan perhitungan nilai rata-rata metrik kinerja dan visualisasi hasil dalam bentuk grafik perbandingan untuk memudahkan interpretasi performa keempat varian network.
