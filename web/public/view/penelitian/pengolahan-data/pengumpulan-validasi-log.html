Bab 4.5.1

Pengumpulan dan Validasi Log

Halaman ini menampilkan proses pengumpulan log transaksi dari API masing-masing network blockchain Hyperledger Fabric. Log yang dikumpulkan mencakup seluruh data transaksi dari keempat varian jaringan: Fabric 2 RAFT Standard, Fabric 2 RAFT Variant, Fabric 3 RAFT Standard, dan Fabric 3 RAFT Variant.

Setiap log transaksi akan divalidasi untuk memastikan kelengkapan dan konsistensi data. Proses validasi mencakup pengecekan integritas data, kelengkapan field yang diperlukan, dan konsistensi timestamp. Data yang telah tervalidasi akan digunakan untuk analisis lebih lanjut dalam pengolahan nilai rata-rata dan visualisasi grafik.
