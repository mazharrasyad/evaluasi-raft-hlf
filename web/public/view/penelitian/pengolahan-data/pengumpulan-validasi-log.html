Bab 4.5.1

Pengumpulan dan Validasi Log

Halaman ini menampilkan proses pengumpulan log transaksi dari API masing-masing network blockchain dan melakukan validasi untuk memastikan kelengkapan serta konsistensi data. Data dikumpulkan dari empat varian jaringan: Fabric 2 RAFT Standard, Fabric 2 RAFT Variant, Fabric 3 RAFT Standard, dan Fabric 3 RAFT Variant.

Validasi dilakukan dengan memeriksa jumlah transaksi yang berhasil disimpan, memverifikasi struktur data, dan memastikan tidak ada duplikasi atau kehilangan data selama proses simulasi.
